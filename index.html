Как пользоваться

  1. Выберите раздел или вставьте ссылку на конкретную страницу.
  2. Заполните utm_source, utm_medium, utm_campaign. utm_content и utm_term — по желанию.
  3. Скопируйте готовую ссылку. Для рекламы удобнее универсальная: в ней достаточно менять to.
UTM-метки не меняют содержимое страницы — они передают данные в Яндекс.Метрику и другие системы аналитики. Для Яндекс.Директа: yandex / cpc. Для VK: vk / social. Для Telegram: telegram / social. Для QR: qr / offline.
